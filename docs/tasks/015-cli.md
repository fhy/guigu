# Task 015: CLI 独立运行（clap）

## Background

001–014 已交付完整嵌入库（运行时/工具/适配器/session/远程协议/server/ACP）。当前 `src/bin/main.rs` 是 004 的最小示例（echo/交互式）。三期需要**CLI 独立运行**：一个真实可用的命令行程序，既能交互式跑 agent，也能以 ACP agent 身份被编辑器拉起——验证「Embeddable + 可独立运行」双目标。

## Goal

- 用 **clap** 建正式 CLI 二进制 `guigu`
- 两个模式：**交互式 REPL**（standalone）与 **`--acp`**（serve ACP over stdio，供编辑器拉起）
- 复用 013 `AgentServer` + 007 adapters（OpenAI/Anthropic）+ 005/006 内置工具装配真实 agent；session 走 009 `JsonlSessionStorage`（可 `--log` 指定目录，支持崩溃恢复/续聊）

## Design Notes

### CLI 面（src/bin/guigu.rs）

```text
guigu [OPTIONS] [COMMAND]

Commands:
  run     交互式 REPL（默认，可省略）
  acp     以 ACP agent 身份 serve stdio（供编辑器子进程拉起）
  help

Options:
  -m, --model <MODEL>       模型 id（如 gpt-4o-mini / claude-3-5-...）
  -p, --provider <PROVIDER>  openai | anthropic（默认 openai）
  -s, --session <ID>        加载/续用指定 session（缺省则新建）
  -c, --cwd <DIR>           工作目录（默认当前目录）
  -l, --log <DIR>           session JSONL 存储目录（默认 ~/.local/state/guigu/ 或 env 指定）
  -k, --api-key <KEY>       provider API key（缺省读 env：OPENAI_API_KEY / ANTHROPIC_API_KEY）
  -h, --help
```

- 用 `clap`（derive `Parser`/`Subcommand`）；新增依赖 `clap`（architecture 5 已列「clap 二期可选」，本任务落地），`derive` feature。
- 行编辑库（rustyline/dialoguer）**不引入**，保持 minimal；REPL 读 `tokio::io::stdin` 逐行。

### 装配（src/bin/guigu.rs 内部函数）

- 依据 `--provider` 选 007 adapter（`OpenAiProvider`/`AnthropicProvider`，读 `--api-key`/env）；`--model` 传入。
- 工具集：005 read/write/edit + 006 bash（注入 `FileMutationQueue`）；写入工具工作目录锚定 `--cwd`。
- `AgentServer` + `create_session`/`spawn_lane`：session 持久化用 `JsonlSessionStorage::open(--log/--session)`；`--session` 存在则 `load_session` 续聊，否则新建。
- REPL：读行 → `server.prompt(session, lane, vec![User text])` → 订阅事件流把 text/tool 进度打印到 stdout → 直到 `AgentEnd` 或 run 结束；空行忽略；`/quit` 或 Ctrl-D 退出（退出前 `server.shutdown`）。

### ACP 模式

- `guigu acp`：装配同 REPL，但以 `AcpAgent::new(server).serve_stdio()` 进入（014 定稿），不再读 stdin 交互；供编辑器以子进程拉起（stdio 上的 JSON-RPC 2.0）。

### 错误处理

- CLI 层错误统一映射为退出码：装配失败/参数非法 → 非零退出 + stderr 提示；REPL 内单次 prompt 错误打印但不退出。
- 无 `unwrap()`；`main` 返回 `Result<(), Box<dyn std::error::Error>>` 或自定义 `CliError`（thiserror）。

### 边界声明（明确不做）

- **TUI**（全屏交互界面）不在本任务（属后续）；REPL 为行式。
- **MCP server 注册**（`--acp` 的 initialize 携带 MCP）：不在本任务（014 已声明）。
- **插件/工具动态注册**：不在本任务（插件延后）；工具集内置固定装配。
- **跨进程 session 写并发**：不在本任务（009/012 边界）；单进程多 lane 由 013 支持。
